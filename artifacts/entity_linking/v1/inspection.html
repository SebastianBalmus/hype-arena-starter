How to interpret this report

This is a deterministic preprocessing audit, not a truth classifier or a measured NER accuracy score. The report covers the complete practice dataset. A row with no linked mention may use a pronoun, an unlisted short name, or no named entity at all.

Offsets in the CSV are zero-based Python character offsets, with the end excluded. The registry preserves IDs when the lexicon is reordered or expanded.
